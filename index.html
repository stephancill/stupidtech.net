Stupid Technology

Stupid Technology is a suite of applications each focused on best-in-class proficiency at simple use cases.

Use case Product
Reliably use web-based Ethereum applications on iOS without switching apps. stupid wallet: An Ethereum wallet for iOS/macOS with a Safari extension. (feedback)
Debug web apps on iOS. devtools: An iOS app with a Safari extension that can be invoked on any page like Chrome DevTools.
A fast and reliable public EVM RPC. evm.stupidtech.net: A production RPC proxy that races public providers.
Never look up a block explorer URL for a chain again. stupid explorers: Routes requests to a random EIP-3091-compliant block explorer for any chain, keyed by chain ID.
Cheap & fast token search for wallets. stupid tokens: Chain-agnostic token search and bulk token pricing API.
Fast and reliable IPFS gateway. ipfs.stupidtech.net: A production IPFS proxy that races public providers.
One-command file uploads. stupid-upload: An agent-friendly interface for free temporary uploads and paid long-term uploads. (agent skill)
Share transactions as URLs. txlink: An app that encodes wallet requests as URL params and lets any wallet connect to complete them.
Fast search with duckduckgo-style bangs. stupid search: A lightweight bang-compatible search redirector.
Give an agent access to a shared calendar so it can manage events for you. agent-cal: A calendar API for AI-agent-managed Apple Calendar subscriptions.
Extract signal from apps designed to waste your time. stupid social: A social app aggregator that shows notifications and limited, high signal content. (feedback)
Effortlessly create custom widgets on iOS. stupid widgets: An app for AI-assisted widget creation, backwards compatible with Scriptable.
TOTP generator that stays out of your way. stupid totp: A TOTP app that sorts codes by last use and hides codes you don't use by default.
Build and run iOS apps from anywhere. stupid-app-cli: A CLI for creating, building, signing, and distributing iOS apps.
